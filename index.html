Hi, I'm the Founder of Friday Skates

My name Is Henri, and for 5 years skateboarding has been my passion. I started FridaySkates here in New Orleans with the main goal of fostering a larger skateboarding community. Right now the business is largely focused on skate lessons, however ultimately my vision for FridaySkates is hosting skateboarding events locally and starting my own clothing brand alongside the lessons.

How to Connect Google Maps API

Your spot finder currently uses Leaflet & OpenStreetMap which works out-of-the-box for free without any API keys!

If you prefer to use official Google Maps JavaScript API, follow these 3 simple steps:

  1. Get an API Key: Go to the Google Cloud Console, create a project, and enable the Maps JavaScript API to generate an API key.
  2. Add Google Script: Include this tag in your HTML <head>:
    <script src="https://maps.googleapis.com/maps/api/js?key=YOUR_API_KEY"></script>
  3. Replace Map Script: Swap the Leaflet initialization function with standard Google Maps syntax:
    const map = new google.maps.Map(document.getElementById("map"), { center: { lat: 29.9511, lng: -90.0715 }, zoom: 12 });
